# Bash Backup Script

Скрипт на Bash для создания резервных копий указанной папки.

## Что делает

- Проверяет, существует ли исходная папка.
- Создает папку для бэкапов, если её нет.
- Архивирует указанную папку в `.tar.gz`.
- Добавляет в имя архива дату и время (чтобы не перезаписывать старые копии).
- Проверяет успешность создания архива.

## Как использовать

1. Откройте скрипт и укажите нужные пути в переменных `SOURCE_DIR` и `BACKUP_DIR`.
2. Запустите:

\`\`\`bash
bash backup.bash
\`\`\`

## Пример вывода

\`\`\`
Создана папка для бэкапов: /home/user/backups
Начинаю архивацию /home/user/projects...
Успех! Архив создан: /home/user/backups/backup_2026-10-17_19-45.tar.gz
\`\`\`

## Требования

- Linux или WSL
- Bash
- Утилита `tar`
